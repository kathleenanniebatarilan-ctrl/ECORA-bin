Vendo unit (front view)

Size183 cm (6 ft) tall, about 100 cm wide; base buried 3 in (7.6 cm)
BodyStainless steel wire mesh for almost the whole height, with a 1 in blue plastic (tank-type) cap band at the top under the solid lid
Inlet15 cm hole at 130 cm height, fits a 2 L bottle; sensor sits behind it
SensorsInductive (metal can) and capacitive (plastic bottle), read by an ESP32
Sorting cylinder2 ft (61 cm) horizontal cylinder in line with the inlet, resting on top of the divider and split lengthwise into two half-shells; each half swings open to its own side, driven by a servo
Vendo unitQR code panel, green lamp (session active), red lamp (points redeemable), paper token slot
WebsiteStudent scans the QR, logs in with complete name, ID number and password, sees points, and chooses Deposit or Redeem. Redeem is locked until points are enough. Deposit runs a 30-second countdown that resets to 30 each time an item is detected.
Vendo housingRectangular enclosure about 36 x 50 x 22 cm built into the front of the cylinder body, with about a quarter of its depth sticking out through the mesh and its panel facing out. Inside: ESP32 board (built-in WiFi), servo driver board, thermal printer with paper roll, power supply and wiring. Switch on X-ray view to see it.
Back doorDouble-leaf door at the back, padlocked, opens outward so staff can take out the sorted bottles and cans for selling

Possible code (ESP32, Arduino IDE)

#include <WiFi.h>
#include <HTTPClient.h>
#include <ESP32Servo.h>

// Pins
const int IND=34, CAP=35;          // inductive (metal), capacitive (plastic)
const int LED_GRN=14, LED_RED=27;  // session active, redeemable
Servo doorTin, doorPlastic;        // each servo swings one half of the sorting cylinder

// Placeholder values: set after your costing
const long PTS_PLASTIC=20, PTS_CAN=10, TOKEN_COST=100;
const unsigned long SESSION_MS=30000;   // 30 seconds

bool sessionOn=false;
String user="";                    // student logged in on the website
long points=0;
unsigned long lastItem=0;          // time of the last item (timer restarts here)

void setup(){
  pinMode(IND,INPUT); pinMode(CAP,INPUT);
  pinMode(LED_GRN,OUTPUT); pinMode(LED_RED,OUTPUT);
  doorTin.attach(32); doorPlastic.attach(33);
  doorTin.write(0); doorPlastic.write(0);   // closed
  Serial2.begin(9600);                      // thermal printer
  WiFi.begin("ECORA-WIFI","password");      // the website is hosted online
}

void loop(){
  // 1. Ask the website: did a student log in and tap Deposit? did they tap Redeem?
  checkServer();

  if(sessionOn){
    // 2. Sense the item, open the matching half, add points, restart the 30 s timer
    if(digitalRead(IND)==HIGH) item(doorTin, PTS_CAN);
    else if(digitalRead(CAP)==HIGH) item(doorPlastic, PTS_PLASTIC);

    // 3. Red lamp on when points can pay for a token
    digitalWrite(LED_RED, points>=TOKEN_COST);

    // 4. No item for 30 seconds: end the session and log the student out
    if(millis()-lastItem > SESSION_MS) endSession();
  }
}

void item(Servo &d, long pts){
  openHalf(d);
  points+=pts;
  lastItem=millis();               // countdown goes back to 30 seconds
  sendPoints(user,points);         // website shows the new total
}

void startSession(String u){ user=u; sessionOn=true; lastItem=millis(); digitalWrite(LED_GRN,HIGH); }
void endSession(){ sessionOn=false; user=""; digitalWrite(LED_GRN,LOW); digitalWrite(LED_RED,LOW); }
void openHalf(Servo &d){ d.write(90); delay(1200); d.write(0); }

void redeem(){
  if(points>=TOKEN_COST){ printToken(); points-=TOKEN_COST; sendPoints(user,points); }
}

// Website calls (use HTTPClient to your own server API)
void checkServer(){ /* GET: logged-in user, deposit pressed, redeem pressed */ }
void sendPoints(String u,long p){ /* POST the new points to the database */ }
void printToken(){ Serial2.println("ECORA TOKEN  PHP 50"); Serial2.println("\n\n"); }

This is a starting skeleton, not tested hardware code. The three website calls need your real server and database. The password check must happen on the server, which stores passwords hashed; the ESP32 never sees them. The sensor outputs also need a voltage divider (see materials).

Materials list

BodyStainless steel wire mesh, stainless angle bar or tube frame, steel base plate (buried 3 in)
Top1 in blue HDPE plastic band (water tank type), solid lid
Sorting cylinder2 ft pipe about 24 cm wide (stainless or HDPE) cut lengthwise into two halves, hinges along the top, a servo and linkage per half, a closed back end
InsideSteel partition sheet (the divider) running from the floor up to the top cap and wrapping around the cylinder, chute guides
ControllerESP32 DevKit board
SensorsInductive proximity LJ12A3-4-Z/BX (metal cans), capacitive proximity LJC18A3-H-Z/BX (plastic bottles)
Actuators2 servos (SG90 for light doors, MG996R if the doors are heavy)
Student accessWeatherproof printed QR code, ESP32 WiFi, hosted website with a database for accounts and points
Token58 mm thermal printer (TTL) and thermal paper roll
ControlsGreen and red indicator lamps (LEDs)
Power12 V 5 A adapter, 5 V buck converter, fuse
WiringVoltage dividers or level shifter (sensors output 12 V, ESP32 takes 3.3 V), wires, terminal blocks
Vendo housingWeatherproof metal or plastic enclosure for the electronics
Back door2 door leaves with hinges, handle, padlock or key lock, rubber seal against rain
